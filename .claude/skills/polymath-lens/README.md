# polymath-lens

The "heart" of the autonomous-hive-agent organism (see
[`autonomous-hive-agent`](../autonomous-hive-agent/)). Adds one short cross-domain
synthesis note — engineering/economics/governance/design/federation — to a **final
deliverable only**: an `AUDIT_LEDGER.md` entry, a roadmap update, a session-harvest
summary. Never runs on ordinary chat replies, never taxes day-to-day speed.

## Why

Leonardo's notebooks never stayed in one lane. This skill is that habit, deliberately
narrow: the last thing added to a finished piece of work, naming what it touches beyond
its own domain — only when that connection is real, never forced.

## The one rule

**A forced connection is worse than none.** If a finding is purely engineering with no
other-domain shadow, say nothing. See [`SKILL.md`](./SKILL.md) for the worked examples
(colony.py's replay gap genuinely touches three domains; wallet.py's connection bug
touches none).
