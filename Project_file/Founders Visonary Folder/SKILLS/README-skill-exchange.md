# The Skill Exchange — compounding team knowledge

**What this is:** every proven workflow from any session becomes a SKILL file here. Any team member — Claude (any model), Mistral, Grok, Founder — can adopt, adapt, and improve any skill in any future session. Skills are cross-pollinating: a backend skill often serves the frontend builder and vice versa. The list only grows.

## Skill file format (keep them under ~25 lines)
```
# SKILL: <verb-first name>
Origin: <member + date + evidence link (PR/commit/run)>
Use when: <trigger>
Steps: <numbered, concrete>
Gotchas: <the mistakes already paid for>
```

## Exchange rules
1. **Adopt freely, credit origin.** Improving a skill = edit in place + add your name to Origin.
2. **Spot-a-skill duty:** whenever you finish a task the second time, or watch a teammate repeat a flow, STOP and write it as a skill. Fable's note to each member is in TEAM_CHARTERS.md §your-name.
3. **One skill per file**, filename `skill-<name>.md`.
4. **Retire, don't delete:** obsolete skills get `> DEPRECATED: <why> <replacement>` at top.
5. New sessions of ANY member: skim this folder BEFORE starting work — the mistakes here are already paid for.
