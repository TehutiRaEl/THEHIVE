Both are 1536 x 1024 PNG files.

## How to read them

- **The sketch outranks the mockup** where they differ, and both outrank the text of any
  plan. The founder's later words outrank both.
- **Every number in the mockup is illustrative**, not data (for example "11,342 nodes",
  "64 online", "37% CPU", "42 C", "12d 4h 32m"). Each one becomes a live number or "no data"
  in the build (front-end Batch F3). Where the sketch and the mockup disagree about a number
  (for example which value is SOUL and which is ELO), the plan records the choice.
- **The mockup has since been extended by the founder's later instructions:** the centre
  graph gets 15 circles (adding Ventures, Treasury and the Queen, with a halo and a crown),
  SOUL is a later DAO-phase idea and is not a live figure, the bottom bar keeps only
  honest tiles, and there is a light mode as well as a dark one. See
  `docs/FRONTEND_MASTER_PLAN_2026-11-14.md` (PR #263) and `docs/FOUNDER_ANSWERED`
  entries FE-001 to FE-008.
- Element-by-element transcriptions of both images are in the master plan, Appendix C.
