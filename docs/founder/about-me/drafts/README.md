# About-Me / Drafts

> **Plain words:** unfinished work by the founder — not yet decided, not yet
> published, not yet anything but a draft.

## What belongs here

Founder drafts: unfinished writing, half-formed plans, sketches, notes toward
a book, a post, a speech, a document — anything Mac started and has not
finished or approved. One draft per file, named plainly, dated, marked DRAFT
at the top with the date it was last touched.

A draft is not a promise. A draft is not a decision. A draft is not published.

## What does NOT belong here

- Finished, published work — that is not a draft any more.
- Ideas → `../ideas/` (then the pool at `../../ideas/`).
- Plans → `../plans/`.
- Updates → `../updates/`.
- Anyone else's drafts. This folder is the founder's only.

## Rules

- **Never publish a draft.** Never share it outside, never post it, never
  present it as finished. Publishing is founder-only.
- **Never silently edit or "finish" a draft.** An agent may suggest changes
  in a separate note, clearly marked as a suggestion — it never rewrites the
  founder's draft in place.
- **Never delete a draft.** If the founder drops it, mark it dropped with the
  date and his reason, and keep it as a record.
- If a draft becomes a plan, copy it to `../plans/` and note the move here.
  If a draft becomes finished work, note where the finished work lives and
  mark the draft superseded — keep the draft, do not erase it.
