## Rules for this folder

- Only audits the founder ordered (or expressly approved) go here. Say who
  ordered each one and when, in the file or in this index.
- Files are filed as-is. Corrections go in a new dated file or addendum, never
  by silently editing a filed audit.
- Nothing in this folder touches the constitution (`soul.md`,
  `.queen/soul.md`) or any workflow file.
