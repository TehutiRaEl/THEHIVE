# Mogul wholesale study — docs/mogul

## What this is

`MOGUL_WHOLESALE_CORPUS.md` is the working corpus of the Mogul
wholesale study loop: wholesale real estate studied as entrepreneurial
arbitrage, built up topic by topic from public, free sources only.
This snapshot holds sections 1–39 and 41 (section 40, unbounded
harvesting, was still in research when this PR was filed and will
follow in a later PR), rules 1–123, about 3.3M credits used of the
100M study budget. Every factual claim in the corpus was
checked against live sources; claims that failed verification are
logged as corrected or unverified in the corpus itself — the corpus
is a verified record, not a set of assertions.
