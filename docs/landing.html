The Colony Map

Each repository is a colony with a specialized role. They communicate via the Hive Bus (automatisch), share a canonical constitution (soul.md), and settle value in SOUL tokens.

CORE COLONY
THEHIVE
Governance engine, agent population, SOUL ledger, Phaser world map, Three.js Cortana oracle. The brain of the federation.
QUEEN / META
sovereign-hive-meta
Canonical soul.md constitution authority. Dispatches constitution updates to all colonies via GitHub Actions repository_dispatch.
AUTOMATION BUS
automatisch
Self-hosted Zapier alternative (AGPL-3.0). The nervous system — cross-colony event routing, SOUL economy triggers, LLM failover alerts.
REVENUE / ORCHESTRATION
aether
TypeScript/Next.js license authority with cross-colony task orchestration. RevenueSplitter.sol handles SOUL settlements on Sepolia.
LLM GATEWAY
kimi-gateway
8-provider free LLM waterfall (Ollama → Moonshot → SiliconFlow → DeepSeek → Zhipu → Groq → OpenRouter → Gemini). Dynamic OmniRoute scoring.
ACADEMY A
free-programming-books
40+ language knowledge base. RAG corpus ingested into ChromaDB. Agents ground responses in curated programming literature.
ACADEMY B
freeCodeCamp
Full CS/math/programming curriculum. Curriculum units become hive tasks agents complete for SOUL rewards.

DUAL-LENS FRAMEWORK

Devil's Advocate + Childlike Wonder

Every architectural decision passes through two lenses before implementation. Not optional. Not aspirational. Non-negotiable.

😈

  • 1. Radical Innocence — suspend all assumptions
  • 2. Five Whys — trace root cause to bedrock
  • 3. Devil's Interrogation — steel-man every failure mode
  • 4. Shadow Inventory — name what we're afraid to name
  • 5. Paradox Pivot — the obstacle IS the path
✨
Childlike Wonder
  • 1. Wonder Weave — ask "what if anything were possible?"

SEVEN-LAYER ARCHITECTURE

How It All Fits Together

Layer 0  Oracle Cloud Always Free — 4 ARM cores, 24GB RAM
Layer 1  Infrastructure — Postgres · Redis · Traefik SSL
Layer 2  Queen (sovereign-hive-meta) — soul.md · hive.yml · GitHub Actions dispatch
Layer 3  Hive Bus — automatisch (webhooks) · n8n (complex flows)
Layer 4  Core Colony (THEHIVE) — FastAPI · Phaser world · Three.js Cortana
              ├─ /v11/*        main API (chat, agents, arena, economy)
