# The Bridge — Complete Architecture

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    THE BRIDGE — Complete Architecture                     │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │  LAYER 1: CAPTURE ENGINE                                            │   │
│  │  • Detects session end, interruption, or limit hit                 │   │
│  │  • Extracts full conversation history                              │   │
│  │  • Captures decisions, rejected approaches, rationale              │   │
│  │  • Preserves code, schemas, and architectural decisions           │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                              ↓                                              │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │  LAYER 2: COMPRESSION ENGINE                                        │   │
│  │  • Uses AIST protocol for 60x compression                          │   │
│  │  • Preserves essence, decisions, memory, and threads              │   │
│  │  • Maintains constant size regardless of session length           │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                              ↓                                              │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │  LAYER 3: SOVEREIGN STORAGE                                         │   │
│  │  • Stores in neuromcp (hyperdimensional memory)                    │   │
│  │  • Indexes in M3 Memory (contradiction detection)                 │   │
│  │  • Archives in Project Memory.MD (human-readable)                 │   │
│  │  • Syncs to GitHub bridge repo (portable, accessible)             │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                              ↓                                              │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │  LAYER 4: INJECTION ENGINE                                          │   │
│  │  • Auto-injects into any AI platform (Claude, DeepSeek, Grok, etc.)│   │
│  │  • Supports browser extensions, CLI, and API modes                │   │
│  │  • One-click continuation — no copy-paste                         │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                              ↓                                              │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │  LAYER 5: EVOLUTION ENGINE                                          │   │
│  │  • Analyzes every bridge for success/failure                      │   │
│  │  • Optimizes compression based on what worked                     │   │
│  │  • Learns which AI platforms are best for which tasks             │   │
│  │  • Adapts injection strategies based on platform changes          │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

All five layers are architectural targets. Live engines are not present in this environment.
