# api/auth

Authentication Module — Sovereign Hive v11.0

## Functions

- `create_access_token()` — Create a JWT access token.
- `verify_websocket_auth()` — Verify WebSocket authentication token.
- `create_refresh_token()` — Create a refresh token with longer expiry.
- `decode_token()` — Decode a JWT token without verification.
- `is_token_expired()` — Check if a token is expired.
