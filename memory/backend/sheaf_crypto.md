# sheaf_crypto

Sheaf Encryption — Fernet-based encryption for guild secrets.

## Classes

- `SheafCrypto` — Encrypts and decrypts guild secrets using Fernet (AES-128-CBC + HMAC).

## Functions

- `encrypt()` — Encrypt a string, return base64 ciphertext.
- `decrypt()` — Decrypt base64 ciphertext back to string.
