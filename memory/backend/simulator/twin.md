# simulator/twin

Digital Twin Simulator — Sovereign Hive v11.0

## Classes

- `DigitalTwinSimulator` — Monte Carlo simulation engine for the Sovereign Hive.

## Functions

- `monte_carlo_proposal()` — Simulate proposal passage using Monte Carlo.
- `colony_growth_simulation()` — Simulate colony wealth growth over time.
- `hyperparameter_optimization()` — Simple hyperparameter optimization using random search.
- `sensitivity_analysis()` — Perform sensitivity analysis on key parameters.
- `agent_behavior_simulation()` — Simulate agent behavior and ELO evolution over time.
