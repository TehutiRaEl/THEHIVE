# audit_chain

Tamper-evident audit chain using SHA-256 linked hashes.

## Classes

- `AuditChain` — Tamper-evident audit chain for all governance actions.

## Functions

- `compute_hash()` — Compute linked hash for an audit entry.
- `verify_chain()` — Verify the entire audit chain for tampering.
