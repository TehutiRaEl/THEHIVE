# core/arena

Gladiator Arena — Sovereign Hive v11.0

## Classes

- `GladiatorArena` — Constitutional court of the hive.

## Functions

- `create()` — Create a new arena challenge.
- `bet()` — Place a bet on an arena challenge.
- `challenges()` — List arena challenges with optional status filter.
- `fallen()` — List fallen ideas from the Hall of Fallen Ideas.
- `resurrect()` — Resurrect a fallen idea.
- `get_challenge()` — Get a specific challenge by ID.
- `get_challenge_history()` — Get projection history for a challenge.
- `get_stats()` — Get arena statistics.
- `simulate()`
