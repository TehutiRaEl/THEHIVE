# economy/utility_economy

Utility Economy — Sovereign Hive v11.0

## Classes

- `UtilityEconomy` — Agents earn SOUL through real-world utility.

## Functions

- `get_multiplier()` — Get agent's utility multiplier (with decay).
- `credit_utility()` — Credit SOUL with utility multiplier applied.
- `get_metrics()` — Get agent's utility metrics.
- `leaderboard()` — Get utility leaderboard.
- `record_failure()` — Record a failed task (reduces effective multiplier).
- `reset_multiplier()` — Reset utility multiplier to 1.0.
- `get_total_utility()` — Get total SOUL earned through utility across all agents.
- `get_avg_multiplier()` — Get average utility multiplier across all agents.
