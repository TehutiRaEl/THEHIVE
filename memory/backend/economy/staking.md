# economy/staking

Staking Economy — Sovereign Hive v11.0

## Classes

- `StakingManager` — Staking SOUL for governance weight and rewards.

## Functions

- `get_positions()` — Get all staking positions for an agent.
- `get_total_staked()` — Get total staked amount for an agent.
- `get_global_staking_stats()` — Get global staking statistics.
- `get_leaderboard()` — Get staking leaderboard.
- `get_staking_position()` — Get a specific staking position by ID.
- `get_agent_staking_history()` — Get full staking history for an agent.
- `get_total_rewards_claimed()` — Get total rewards claimed by an agent.
- `get_apy()` — Get current APY rate.
- `get_lock_days()` — Get current lock days.
- `get_min_stake()` — Get minimum stake amount.
