# Memory Vault — Navigation Guide

## What Lives Here

The complete Obsidian-compatible knowledge graph of THEHIVE. 101 nodes across 4 categories,
~60 edges, generated by `scripts/generate_memory_vault.py`. Open in Obsidian for visual
navigation with the `_graph.json` as the force-directed map.

## Directory Contents

- `_graph.json` — D3.js + Obsidian graph: 101 nodes (10 colony, 12 guild, 75 module, 4 philosophy)
- `_index.md` — Obsidian vault navigation hub with wiki-links
- `agents/` — Agent lifecycle, genome, ELO, memory, react-engine docs
- `backend/` — One `.md` per Python file, AST-generated: classes, functions, endpoints, imports
- `colonies/` — One page per colony: URL, health path, guild assignments, standard endpoints
- `constitution/` — soul.md summary + governance voting docs
- `economy/` — SOUL token, staking mechanics, doubling-state formula
- `guilds/` — One page per guild (12 total) with responsibilities and relevant endpoints
- `llm/` — LLM waterfall routing, provider list
- `mathematics/` — HDC theory, tesseract 4D math, resonance scoring, frequency mapping
- `open-source/` — Integration research: BabyAGI, CrewAI, MemGPT, OmniRoute, SWE-Agent
- `philosophy/` — The four cognitive lenses used in constitutional reasoning
- `planning/` — Session continuity docs (read most recent first)

## How to Use This Vault

- **Find a concept**: search `_graph.json` nodes or open `_index.md` in Obsidian
- **Understand a module**: read `backend/<path>.md` — has classes, functions, endpoints, imports
- **Check colony status**: read `colonies/<name>.md` then hit the colony's `/colony/health`
- **Trace an idea**: follow `[[wiki-links]]` from any page — the graph is fully connected
- **Update the vault**: run `python3 scripts/generate_memory_vault.py` from THEHIVE root

## Regeneration

The vault is auto-generated. Do not edit `backend/*.md` files manually — they will be
overwritten. Edit the source Python files; the vault updates on the next generation run.
Hand-crafted sections (philosophy, economy, mathematics, agents) live in constants inside
`generate_memory_vault.py` — edit there if the content needs updating.
